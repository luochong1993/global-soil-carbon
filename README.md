# 全球土壤有机碳—无机碳耦合演变机制

本仓库存放《全球土壤有机碳—无机碳耦合演变机制》研究用到的分析、制图与文稿生成代码。对应手稿版本以 v14 数字为科学口径，图表风格以 v18（恢复 v14 视觉）为主文，公式恢复见 v19。

**本仓库只包含代码与文稿生成脚本，不包含原始剖面、气候栅格、模型输出或大图件（约 24 GB）。** 数据与结果需另行存放。

## 目录

- `scripts/` 数据处理、建模、情景集合、制图脚本（按版本编号：v4–v10 为核心分析，v13–v18 为图表与叙事修订）。
- `paper/` 各版 Science 主文/补充材料的 Python 生成脚本（含公式 OMML）。
- `huang_sm.txt` 对照 Huang et al. 2024 *Science* 支撑材料的方法摘录，用于氮致酸化公式核对。

主要分析流程概要：WoSIS 剖面质量控制与等面积样条层位调和 → 两步 SIC（存在分类 + 对数浓度回归及 smearing）与 SOC 制图 → CMIP6 空间换时间平衡态变化 → 深度依赖一阶响应（到 2100 年）→ 独立的 IMAGE 氮肥酸化实验 → MAOC/POC 分割。

## 环境

Python 依赖见 `requirements.txt`。文稿公式转换还需系统安装 [Pandoc](https://pandoc.org/)。

路径默认指向原工作目录 `/workspace/soil_global` 下的 `data/`、`out/`、`figs/`；在其他机器上运行前请按本地数据位置修改脚本中的路径。

## 说明

库存变化不等于已证实的大气净碳源；通径/SHAP 结果为统计关联；氮酸化实验与气候增量未相加。请以对应手稿中的边界条件为准。
